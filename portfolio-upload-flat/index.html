Assignment

Binary and ASCII conversion

Explained how computers store data in bits and bytes, then converted binary strings to decimal and to ASCII text by hand using positional notation.

Reflection

My approach was to convert one byte at a time: binary to decimal with place values, then decimal to a letter with the ASCII table. The challenge was keeping track of byte boundaries in long strings. One miscount shifts every letter after it, so I learned to slow down and check my grouping. The bigger lesson was that every value in a spreadsheet, database or Python program is stored this way underneath, which is why data types and storage size matter when I work with data.

Translating binary messages

Decoded three binary strings and described the process, the main difficulty and why it matters for data analytics.

Reflection

Decoding the messages myself made the idea of encoding concrete. The repeated mistake I had to watch for was the same as in the assignment: losing my place between bytes. It showed me that small errors in how data is read can corrupt the entire output, which is the same reason data validation matters in analytics work.

Read my full post

The three binary strings are translated as follows: "Hello," "This is a binary code," and "I love data."

The process I went through to translate each binary string into words included first interpreting the binary string in ASCII format, which really comes down to following some simple steps. Each 8-bit byte was converted into decimal, a process which leads to mapping binary into decimal using positional notation. For example, each byte of the binary string was processed separately. For instance, 01001000 forms 64 + 8 = 72, which corresponds to letter H in its upper-case form.

The biggest difficulty of the exercise is that because long strings contain many bytes, one has to be very careful about remembering where the next byte starts and ends. One small failure in counting the bytes can lead to total miscounting. If one thought that binary coding is easy, he or she should try to complete this exercises.

Besides that, the exercise revealed the fact that in data analytics, real life data is represented as a binary. Thus, having an understanding of why one should be careful while counting the number of bits after moving on to data processing.

Making hardware requires a huge amount of energy, as well as extracting metals such as copper and cobalt, so emissions from the production process constitute the bulk of lifetime emissions in laptops and phones, and hence also during operation, since electricity is consumed during this phase. Machine language, assembly and high-level languages

Explained the differences between levels of programming languages and the performance trade-offs between low-level control and high-level reliability.

Reflection

Researching this helped me understand why Python is so easy to work with: it hides memory management and hardware details that low-level languages expose. The challenge was explaining trade-offs like garbage collection versus manual memory management in plain language. It gave me more respect for what happens beneath the tools I use every day.

Read my full post

1.Fundamental Differences:

Only machine language can be directly executed by a processor. This language is in the form of code in binary or hexadecimal form. Assembly language can be seen as a visible layer over machine code, whereby every mnemonic can be almost fully matched to a single machine instruction. Although assembly code is not as easy to read as raw numbers, it is still tied to the same hardware. High-level programming languages like Python, Java, and C# allow expressing logic by using variables, functions, loops, and objects, although the method of code translation is the same.

4.Performance Trade-Offs:

While machine code and assembly can achieve the highest speeds of execution, the modern optimization compilers can beat the average results of hand-written code, which allows assembly to be used preferably in small block of code. On the other hand, a programmer working with low level programming languages will have to write memory management procedures himself, which allows him or her to have a broad control but makes the programmer vulnerable to such defects as buffer overflow. In contrast, high-level programming languages like Java and Python employ garbage collection, which eliminates this error but adds additional expenses of execution time and possible performance losses. Assembly code can take advantages of some processor developer’s features, while the majority of high-level programming languages use library functions or operating system functions and compromise control for advantages in terms of reliability and portability.

Excel macro: combining monthly report files

Explained a VBA macro that loops through a folder of workbooks and combines them into one master sheet, including its benefits, risks and how a beginner could learn it.

Reflection

I chose a macro that solves a problem I can picture in an internship: merging a dozen monthly files by hand. Explaining the code line by line (Dir, the Do While loop, End(xlUp)) forced me to actually understand it rather than just copy it. I also learned that macros are a real security risk, which connected nicely to the security lessons later in the course.

Read my full post

1. One macro in the Excel program that I found intriguing combines several monthly report files from different workbooks into one sheet similar to a sales manager who gets a unique file from each of the 12 locations every month.

2. Manually opening the files and copying each one's data is long and prone to errors including omitting files, overwriting rows or repeating the header. This macro does everything with a single click and produces uniform results every time.

3. The macro is written in VBA, and it goes through all the files in the folder. The Dir function locates every .xlsx file, the Do While loop repeats the steps while there are files left, and End(xlUp) allows identifying the last row where new rows can be added. For example, wb.Sheets(1).Range(“A2:F” & lastRow).Copy ws.Cells(Rows.Count, “A”).End(xlUp).Offset(1) copies everything except for the header and pastes it into the first empty row of the master sheet. All the source files are closed after the copying operation without saving them to allow the files to remain unchanged.

4. This macro converts an assignment that should take 30 minutes into a task that takes only a few seconds, and it scales well since handling 50 documents is as simple as dealing with 12 files. However, it may not work properly if the layout of a file is different or the path to a folder is unique, and its use cannot be reverted, so a user is encouraged to create a backup of information.

5. Users are allowed to change the path for the folder, type of file, and range of cells copied. For example, instead of modifying the code, users could be provided with the folder selection option or an additional column showing the origin of a row.

6. Through Microsoft Learn’s Excel VBA reference, users can gain insight into the objects and methods which are being utilized while they can watch how to loop through files in Excel Campus and Wise Owl Tutorials on YouTube. The macro recorder can also help a novice user to learn what code is being written while performing simple tasks in Excel.

7. Macros contain dangerous code, so users should turn on macros only if they trust the source and should always check the code in the VBA editor (Alt + F11) before launching the macros. Microsoft has made it impossible for macros to be launched from the files downloaded via the web, and keeping the trusted files in Trust Location would be the safest option rather than changing all Excel macro settings.

Read my full post

Internet and the Web:  The Internet is an international network that links billions of computers and gadgets through wires, routers, and protocols such as TCP/IP. The World Wide Web is one of the services operating on the Internet. To summarize, the Internet functions as a road while the Web functions as traffic on this road.

Underlying Technologies: Data is sent in packets where routers route the traffic based on IP address and names such as amazon.comLinks to an external site. are translated into IP addresses by DNS. A web browser receives a request in order to request the page from a web server and obtain HTML data. The web allows linking different pages to web servers through hyperlinks.

Challenges and Ethical Considerations: A lot of free services available online make money by means of monitoring people’s activities on the web. It creates questions of privacy. Phishing, breaches of data, and inequality in broadband access create other challenges. More privacy measures, improved practices, and investment into broadband and digital literacy should help solve many problems occurring online.

I came into IST 110 comfortable with Excel and some Python from IST 140, and I assumed most of the course would be review. It wasn't. The technical pieces stretched me in new directions, especially SQL, HTML and JavaScript, but the bigger change was in how I think about information itself.
